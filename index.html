보행신호기 BLE 탐지

경찰청 음향신호기 R01에 정의된 AHG001+ 광고 이름 규칙으로 주변 기기를 탐지하는 연구용 페이지입니다. 장치 연결·제어·데이터 쓰기는 구현하지 않았습니다.

⚠️ 횡단 안전 판단용이 아닙니다. 검색에 성공해도 해당 장치의 설치 위치, 신호 상태, 적색·녹색 여부는 확인되지 않습니다. 도로에서는 안전한 인도에서만 사용하세요.

01 · 탐지 설정

경찰청 R01 / SafeLight 확인값. R03 적용 여부와 현장 활성화 여부는 미검증.
실험적 연속 스캔 결과를 화면에서 걸러주는 표시 기준이며, 실제 거리나 브라우저 스캔 범위를 제한하지 않습니다.
브라우저 상태 확인 중
모드 차이와 브라우저 설정

기본: Chrome의 장치 선택 창에서 이름이 일치하는 장치를 확인. GATT에 연결하지 않음.

실험: requestLEScan() 지원 시 광고 데이터와 RSSI를 연속 표시. Android Chrome에서 chrome://flags/#enable-experimental-web-platform-features를 켜야 할 수 있으며 지원이 보장되지 않음.

선택 장치 관찰: watchAdvertisements() 지원 시 선택한 장치의 광고를 관찰. 지원하지 않는 브라우저는 동작하지 않음.

Web Bluetooth 사용에는 HTTPS 또는 localhost 환경 및 사용자의 직접적인 클릭이 필요합니다.

02 · 선택된 장치

아직 선택되지 않음
기본 모드를 눌러 주변 장치 선택 창을 열어 보세요.

탐지 결과

0개신호 상태: 미확인
아직 수집된 광고 패킷이 없어요. 기본 장치 선택만으로는 광고 원본이나 RSSI가 제공되지 않을 수 있습니다.

03 · 세션 기록

데이터는 서버에 자동 업로드되지 않고 이 탭의 메모리에만 보관됩니다. JSON 공유 시 기기 식별자 등 개인정보를 확인하세요.
범위: 장치 이름·광고 패킷을 이용한 수동 식별만 수행. 무선신호 송출, GATT 연결, Characteristic 읽기/쓰기, 제어 명령 기능은 없음.
근거: 경찰청 R01 표준규격 (2024, 25쪽) · SafeLight 개발 문서 · MDN requestDevice.
제한: 이 버전에서는 교차로 신호정보를 표시하지 않으며, R03 규격과 최신 설치 장비의 호환 여부는 확인되지 않았습니다.
