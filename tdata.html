보행신호 데이터 관측

서울 T-DATA 10381 API의 교차로별 원본 상태코드·잔여값·전송시각을 확인하는 연구용 대시보드입니다.

실제 횡단 판단에 사용 금지. 방향 코드와 현장 보행자 신호등의 대응이 확인되지 않았습니다. API 응답에는 수초의 지연이 있을 수 있으며, 남은 시간은 수신 당시 원본 스냅샷입니다. 현재 남은 시간으로 자동 카운트다운하지 않습니다.

교차로 선택

실시간 조회는 로컬 Python 서버에서만 지원합니다. GitHub Pages에서는 과거 실측 기록을 볼 수 있습니다.
